# Refonte du site SGB – Sefaj Général Bâtiment

Version statique, épurée et rapide de https://sgb-deco.fr (remplace le WordPress/Elementor).
Un seul fichier `index.html` (CSS/JS inline, Google Fonts uniquement), généré avec ChatGPT puis relu.

## Avant mise en production
- Rapatrier les images dans `images/` (elles pointent encore vers sgb-deco.fr/wp-content).
- Créer l'adresse contact@sgb-deco.fr et la remplacer dans le HTML et le JSON-LD.
- Brancher le formulaire sur Formspree (instructions en commentaire dans le code).
- Rédiger la page Mentions légales (SIRET, assurance décennale, hébergeur).
